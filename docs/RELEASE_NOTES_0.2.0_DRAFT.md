# Project Compass v0.2.0 — 实验性输入规划改进（草稿）

**尚未发布。拟定 Tag 为 `v0.2.0`，拟在 GitHub 标记为 Pre-release。需先解决发布检查报告中的验证脚本阻断，再经维护者第二次明确批准。** 本草稿不是合并或发布授权。

本版本改善从自然语言需求进入 GitHub 项目初查的入口，继续使用有限词表和规则，不调用模型，也不需要模型密钥。

- 根据明确表达推断寻找已有项目、开发创意、学习探索或未知意图，保留原始需求、条件和未映射要点。
- 组合任务与平台等条件，最多生成两条互补查询；陌生中文主题使用中文分词/相邻短语回退，中英文任务词可以共同保留。
- 对部分模糊、只有平台没有任务或查询过长的输入先给简短澄清，避免静默截断后检索。
- 保留 V1 的真实 GitHub 数据来源、README 证据引用、本地报告/原始响应留档和离线重放。旧留档默认使用原始查询和已采集候选顺序。
- AI 导入导出继续使用 v1 文件协议；Compass 不自动调用模型，结构/引用检查不证明 AI 分析语义正确。

这是**有限规则入口，不是通用 AI 语义搜索**。未知领域、跨语言、复杂否定或组合意图仍可能漏条件或返回不相关候选。开发案例中，中文药品到期提醒虽保留了主任务，仍未找到有足够适配证据的候选；“没网也能用”、书签同步等也未完整映射。宽泛技术词可能召回不同领域。

README 作者声明、文字关联和命令成功都不等于软件已经安装实测、满足用户任务或证明存在市场机会。没有验证总体准确率、竞品覆盖率、用户价值或持续使用需求。

使用 Node.js 24.19.x / npm 12.2.0，按锁文件安装并构建后运行 CLI。输出解释、帮助和诊断目前主要为中文。代码使用 MIT 许可证；依赖保留各自许可。GitHub 源码版本不包含安装包或候选 README 全文；`private: true` 继续阻止 npm 发布，本次不做 npm 分发。
